# Publish token-radar ke GitHub — langkah Kakak

Repo ini siap publish. Yang Ayu tidak bisa lakukan: login GitHub Kakak.
Yang Kakak lakukan (di komputer Kakak, akun zulhampro99):

1. Buka github.com/new (login sebagai zulhampro99).
2. Repository name: `token-radar`. Pilih **Public**. Jangan centang
   "Add a README file". Klik **Create repository**.
3. Di repo baru, klik **Add file > Upload files**, lalu upload SEMUA isi
   folder ini (`main.ts`, `lib/`, `vendor/`, `dashboard/`, `screenshots/`,
   `ref-undercurrent-*.png`, `NOTES.md`, `LICENSE`, `README.md`,
   `gate-check.mjs`, file ini). Klik **Commit changes**.
4. Kirim ke Ayu: URL repo (contoh `https://github.com/zulhampro99/token-radar`)
   + track yang dipilih. Saran Ayu: **Proof Gatekeeper** (radar ini membuktikan
   klaim nilai dengan model + gate check yang bisa diverifikasi).
   Alternatif: Steal the VFY — kurang cocok, karena ini bukan agent live
   dan Ayu tidak punya endpoint publik.
